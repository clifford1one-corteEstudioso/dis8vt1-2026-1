**De las ideas a la propuesta: selección y perfilamiento**

Sergio Majluf — Simón Gallardo

Ya generaste al menos nueve ideas. El trabajo divergente está hecho. Ahora viene la parte más exigente: elegir una dirección y poder defenderla. Este proceso tiene tres pasos.

**Paso 1 — Filtro: ¿qué ideas califican?**

Aplica estas tres preguntas a cada idea. Si alguna responde **No**, esa idea sale del proceso.

| Pregunta de filtro (responde Sí o No por cada idea) |  |
| :---- | :---: |
| ¿Esta idea responde directamente a tu hipótesis o a tu objetivo general? | Sí   /   No |
| ¿El diseño es el motor de la solución (no solo la tecnología o la comunicación)? | Sí   /   No |
| ¿Integra dimensiones físicas y digitales de forma intencionada? | Sí   /   No |

Las ideas con tres **Sí** pasan al Paso 2\. Las demás no son malas ideas — simplemente no son pertinentes para este proyecto en este momento.

**Paso 2 — Evaluación: ¿cuáles son las más sólidas?**

Evalúa cada idea que pasó el filtro con los tres criterios siguientes. Asigna 1, 2 o 3 según el nivel que mejor describe la idea.

| Criterio | 1 — Débil | 2 — Suficiente | 3 — Sólido |
| ----- | ----- | ----- | ----- |
| **Coherencia con la hipótesis** | No se conecta con el problema formulado | Compatible, pero la relación requiere muchos supuestos | Se deriva directamente de la hipótesis y la pone a prueba |
| **Potencial phygital** | Solo digital o solo física, sin integración | Hay elementos de ambas dimensiones, pero la hibridación no está pensada | Integra físico y digital de forma intencionada y coherente |
| **Novedad y apertura** | Reproduce una solución existente sin cuestionarla | Propone algún giro o combinación nueva sobre algo conocido | Abre un espacio no obvio: sorprende y justifica ser explorada |

Suma los puntajes de cada idea. Las de mayor puntaje son tus candidatas. Pero el número no decide solo: una idea con puntaje alto en los tres criterios es tu punto de partida, no tu respuesta final.

**Paso 3 — Justificación: ¿por qué esta y no las otras?**

Elige **una idea** y completa este cuadro. Una respuesta bien argumentada es más valiosa que el puntaje más alto.

| Campo | Tu respuesta |
| :---- | :---- |
| **Nombre o descripción breve de la idea elegida** |  |
| **¿Por qué esta y no las otras? (en una oración)** |  |
| **¿Cómo se articula con tu hipótesis?** |  |
| **¿Qué es lo específicamente phygital de esta idea?** |  |
| **¿Qué necesitas resolver para llevarla al Taller?** |  |

**Recuerda:** *idear es generar posibilidades. Seleccionar es asumir responsabilidad sobre una dirección. No eliges la idea más bonita ni la más ambiciosa — eliges la que mejor articula tu problema, tu hipótesis y tu apuesta de diseño. El Taller comienza con esa decisión.*
